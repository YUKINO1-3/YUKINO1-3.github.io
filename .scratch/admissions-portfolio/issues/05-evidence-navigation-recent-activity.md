# 05: 整合证据导航与 Recent Activity

**What to build:** 将已发布 Work、Note 和 Academic Result 组合成连贯的信息架构，让读者从 Home 快速理解申请者方向，并通过受控分类和 Recent Activity 找到真实证据。

**Blocked by:** 02: 发布第一篇受控 Note; 03: 发布第一个 Work 与 Case Study; 04: 展示经过验证的 Academic Result.

**Status:** ready-for-agent

- [ ] Home 呈现数学建模与计算实验的核心主张、Featured Work、最新 published Note 和紧凑 Academic Snapshot。
- [ ] Works 与 Notes 可以按受控 Subject、Medium 和 Capability 进行可访问筛选。
- [ ] 分类入口由 published 内容派生；没有内容的分类完全隐藏。
- [ ] Capability 列表中的每一项都链接到至少一个 Work 或 Note 证据。
- [ ] Recent Activity 只包含 published Work、published Note 和明确的重要里程碑，不包含 commit feed 或碎片状态。
- [ ] 顶层 Home、Works、Notes、About 导航在直接访问、刷新和移动端状态下保持一致。
- [ ] 浏览器测试验证筛选、空分类、证据链接和 Recent Activity 排序的用户可见行为。
