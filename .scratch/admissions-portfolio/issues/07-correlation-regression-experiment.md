# 07: 交付相关与回归交互实验

**What to build:** 在一个 Case Study 中提供可访问的 React 统计实验，让读者亲自观察样本量、异常值和混杂变量如何影响相关与回归，并理解模型假设、验证方式与局限。

**Blocked by:** 03: 发布第一个 Work 与 Case Study; 06: 完成数字实验室视觉体验.

**Status:** ready-for-agent

- [ ] 读者可以通过键盘和指针调整样本量、异常值、混杂变量及随机种子。
- [ ] 相同参数和随机种子产生可复现结果，重置操作恢复已知状态。
- [ ] 图形以可访问 SVG 或 Canvas 呈现，并提供等价的文本摘要、数值信息和清晰控件标签。
- [ ] Case Study 解释相关与回归的假设、验证、混杂影响、失败案例和不可推出的结论。
- [ ] 减少动效或禁用动画时，实验仍可操作且核心结论完整。
- [ ] 交互代码延迟加载，不阻塞 Case Study 的静态正文。
- [ ] 测试验证用户操作、可复现性、文本替代、边界参数和 reduced-motion 行为。
