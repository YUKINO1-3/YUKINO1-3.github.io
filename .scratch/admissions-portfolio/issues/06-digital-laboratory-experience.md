# 06: 完成数字实验室视觉体验

**What to build:** 将完整 Portfolio 内容路径塑造成克制的数字实验室体验：具有学术排版、清晰层级和轻量实验感，同时让移动端、键盘、屏幕阅读器及减少动效用户获得完整内容。

**Blocked by:** 05: 整合证据导航与 Recent Activity.

**Status:** ready-for-agent

- [ ] 视觉系统使用可复用设计 token，呈现“数字实验室为主、学术排版为辅”的一致气质。
- [ ] 页面从 320 CSS 像素起可用，并在手机、平板、笔记本和宽屏上保持合理阅读宽度与层级。
- [ ] 所有导航、筛选和交互控件可通过键盘使用，焦点清晰，语义名称准确。
- [ ] 动效遵循 `prefers-reduced-motion`，不使用滚动劫持、自定义鼠标或依赖动画才能理解的内容。
- [ ] 色彩对比、缩放、标题层级、替代文本和 landmark 满足 WCAG 2.2 AA 的设计目标。
- [ ] 客户端增强失败时，正文、分类和核心结论仍然可读。
- [ ] 自动无障碍检查与代表性手工检查均被记录并通过。
